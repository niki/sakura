01マルチカーソル編集

VS Code / Sublime Text のように、複数箇所へ同時にカーソルを置いて編集できます。

使い方

Ctrl+Alt+↓ を押すたびに、現在のカーソルの下の行にカーソルが1本ずつ追加されます。Ctrl+Alt+↑ なら上方向。文字入力・削除・矢印移動などの通常操作は、追加した全カーソルに同時に反映されます。

やり直したいときは Ctrl+Shift+U で、直近に追加したカーソルを1本だけ取り消せます。Esc で通常の単一カーソルに戻ります。

マウスでは、Alt+クリック(VS Codeと同じ操作)でクリック位置にカーソルを追加できます。ドラッグした場合は従来通り矩形選択になります。

詳細設計 → マルチカーソル編集 設計リファレンス

02コマンドパレット

VS Code風のコマンドパレット。メニューをたどらずに、名前の一部を入力するだけで機能を実行したり、開いているファイルへジャンプしたりできます。

使い方

Ctrl+Shift+P で呼び出します。日本語の機能名でも、そのローマ字読みでも部分一致検索できます（あいまい検索）。IME変換中の候補にもリアルタイムに反応します。

詳細設計 → コマンドパレット 設計リファレンス

03セッション復元

終了時に開いていたファイルを、次回起動時に自動的に開き直します。既定OFF

設定場所

共通設定ダイアログの「ファイル」タブにある次の2つのチェックボックスで制御します。

  • 終了時に開いていたファイルを次回起動時に自動復元する — これをONにすると、開いていたファイルの一覧が保存され、次回起動時に自動で開き直されます。
  • 未保存の変更内容もバッファから復元する — 上のチェックがONのときだけ操作可能。保存前の未保存の編集内容まで含めて復元します（1つ目のチェックがOFFのときはグレーアウトします）。

詳細設計 → セッション復元 設計リファレンス

04絵文字カラーフォント

😀🎉👍 のようなカラー絵文字を、通常のモノクロ矩形（トーフ）ではなく元の色付きグリフで表示します。ZWJ結合絵文字（👨‍👩‍👧など）やキーキャップ（1️⃣など）の合字表示にも対応。特別な操作なしで、対応環境なら自動的に有効になります。

設定場所

共通設定「全般」タブの描画グループに「絵文字フォントを固定指定する」チェックがあります。OFF（既定）ならシステムの自動選択に任せ、ONにすると指定したフォント固定で絵文字を描画します。同じ場所の「絵文字の合字を有効にする」で合字表示のON/OFFも切り替え可能です。

Windows 8.1相当（DirectWrite 2）に満たない環境では、この機能自体が自動的に無効化され、従来通りの表示になります。

詳細設計 → 絵文字カラーフォント 設計リファレンス

05スクロールバーマーカー

右側のスクロールバー上に、検索結果・ブックマーク・現在のカーソル位置を色分けした短い線として重ね描きします。ファイル全体のどこに何があるか、スクロールせずに一目で把握できます。

  • オレンジ 検索文字列のある行
  • 赤 ブックマークのある行
  • 青 現在のカーソル行

マーカー部分をクリックすると、該当行へ直接ジャンプできます。

詳細設計 → スクロールバーマーカー 設計リファレンス

06置換プレビュー

「置換」ダイアログに検索・置換の文字列を入力すると、実際に置換する前に、カーソルに近い一致箇所を対象として「置換前 / 置換後」のサンプルがダイアログ内にリアルタイム表示されます。意図通りの結果になるか、実行前に確認できます。

挿入・追加・行削除・クリップボード貼り付けなど、位置や外部データに依存する設定の場合はサンプル表示の対象外です（その旨がダイアログ内に表示されます）。

07Undo時の選択範囲復元

選択範囲を削除する操作を Ctrl+Z（元に戻す）で取り消すと、削除前に選択していた範囲がそのまま選択状態に復元されます（VS Code等と同じ挙動）。マルチカーソル編集時も、各カーソルの選択範囲がそれぞれ正しく復元されます。

08キー割り当てプリセット

共通設定「キー割り当て」タブのプリセット選択コンボから、VS Code・Sublime Text・Notepad++等、他エディタ風のキー配置へワンクリックで一括切り替えできます。プリセットは実行ファイルに組み込み済みなので、追加ファイルは不要です。

全キー一覧・プリセット比較表 → キー割り当て一覧

09モダンなステータスバー・ツールバー

ステータスバーとツールバーを、VS Code風のフラットなオーナードロー描画に変更しています。読み上げソフト等のネイティブなアクセシビリティ情報は維持されたまま、見た目だけが刷新されています（ダークモード自体には非対応）。

10単一exe配布

sakura.exe は、これ単体をコピーするだけで動作します。sakura.iniは初回起動時に自動生成され、正規表現エンジンや主要言語のシンタックスハイライト用キーワードも実行ファイルに組み込み済みです。追加の辞書DLLやヘルプファイルなどは、使う場合だけ任意で用意すれば良い設計になっています。

必須/任意ファイルの詳しい一覧 → 単一exe化 ファイル依存関係リファレンス
