01機能別 設計リファレンス

実装済みの独自機能ごとに、なぜその設計になったか・どこで踏んだ不具合をどう直したかまで含めて記録している。

🌸 NKMM_MULTI_CURSOR

マルチカーソル編集

VS Code / Sublime Text風の複数カーソル編集。プライマリからの固定オフセット方式、既存の単一カーソルコマンドを再生する設計、全20パスの変更履歴。

2026-08-30〜31設計パス20 🔍 NKMM_COMMAND_PALETTE

コマンドパレット

VS Code風のコマンドパレット/クイックオープン。接頭辞によるモード切替、ローマ字あいまい検索エンジン、漢字ヒューリスティック、オーナードロー描画。

2026-08-18〜21 📏 NKMM_FIX_EDITVIEW_SCRBAR

スクロールバーマーカー

検索結果・ブックマーク・キャレット行をスクロールバー上に重ね描き。2017年の初版から2026年のスレッドプール化・クリックジャンプまでの二段階の開発史。

2017-06〜2026-08 🎨 NKMM_FIX_COLOR_FONT

絵文字カラーフォント

GDI描画にDirect2D/DirectWriteでCOLR/CPALカラーグリフを重ね描き。ZWJ絵文字合字、キーキャップ結合表示、絵文字フォント固定指定UI。

2026-07-17〜08-17コメント整理 09-01 🔁 NKMM_SESSION_RESTORE

セッション復元

終了時に開いていたファイル(未保存内容含む)を次回起動時に自動復元。「タブ=別プロセス」制約下での保存/復元トリガー設計、セキュリティ修正。

2026-08-14〜09-01 🔧 NKMM_FIX_QUICKJS_MACRO 他

PPA・WSH代替マクロエンジン

外部DLL(PPA.DLL)・外部COM(WSH)依存を、静的リンクしたQuickJSベースへ置き換え。.qjs/.pas/.vbsそれぞれの対応状況とできないこと一覧、未検証項目。
